# TaskFlow

TaskFlow is a simple **Todo application** built with the MERN stack. It is designed to help users create, manage, and organize their tasks through a clean and responsive interface.

## 🚀 Tech Stack

### Frontend

* **React.js**
* **JavaScript**
* **CSS**
* **Tailwind CSS**
* **DaisyUI**

> The project primarily uses normal CSS for styling, but **Tailwind CSS and DaisyUI are also integrated**. Feel free to use them when building new components or improving the UI.

### Backend

* **Node.js**
* **Express.js**

### Database

* **MongoDB**

### Other Tools

* **Git & GitHub**
* **Vite**

## ✨ What TaskFlow Can Do

TaskFlow is being developed as a Todo management application where users will be able to:

* Create tasks
* View tasks
* Update tasks
* Delete tasks
* Manage their todo list
* Organize tasks through a simple interface

More features may be added as development continues.

## 🎨 Styling

The project currently uses a combination of:

* Regular CSS
* Tailwind CSS
* DaisyUI components

If you want to use **Tailwind or DaisyUI**, they are already integrated into the project, so you can use their utility classes and components directly.

## 🛠️ Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd TaskFlow
```

Install dependencies for the frontend:

```bash
cd frontend
npm install
```

Start the frontend:

```bash
npm run dev
```

For the backend:

```bash
cd backend
npm install
npm run dev
```
